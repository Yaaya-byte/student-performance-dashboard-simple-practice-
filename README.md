# Student Performance Dashboard

## Overview
A Power BI dashboard analyzing student scores across subjects (English, Math), 
built from SQL Server data using [class_a, class_b, scores] tables.

## Tools Used
- SQL Server (data source)
- Power BI Desktop (data modeling, DAX, visualization)

## Features
- Combined/appended tables from multiple classes
- Custom DAX measures (Total Score, Average Score)
- Interactive matrix, bar chart, pie chart visuals
- Pass/Fail status breakdown
